# Smart Pantry Manager

A simple Android app that helps users track pantry ingredients and find recipes.

## Features

- Add ingredients with a name, quantity, and unit
- View and remove ingredients from the pantry
- Save pantry ingredients on the device
- Find recipes that match available ingredients
- View cooking instructions
- Check the number of saved ingredients and clear the pantry in Settings

## Built with

- Java
- Android Studio
- Android SharedPreferences for local storage

## Run the app

Open the project in Android Studio, wait for Gradle sync to finish, select an Android emulator or device, and click **Run**.
